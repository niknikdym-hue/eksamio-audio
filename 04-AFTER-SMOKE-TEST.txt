ПОСЛЕ УСПЕШНОГО SMOKE-TEST

Шаг 1.
Не озвучивать всю книгу.

Шаг 2.
Вставить 2–3 реальные страницы книги в:
input/BOOK.txt

Шаг 3.
Сначала прогнать:
python scripts/07_split_book.py

Шаг 4.
Оценить полученные фрагменты в work/chunks/.

Шаг 5.
Только после выбора/создания подходящего русского голоса запускать генерацию.

ВАЖНО:
готовые голоса 0.6B CustomVoice не являются нативными русскими.
Поэтому качество русского аудиокнижного чтения нельзя оценивать только по факту,
что smoke-test «что-то произнёс».

В папке input/voice-reference/ лежат правила будущего теста 0.6B Base.
